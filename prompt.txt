RESEARCH SYNTHESIS (key findings)

Google HDR+/Night Sight/Super-Res Zoom: burst capture → alignment (optical flow/feature) → merged denoised frame; Night Sight = super-res merge + tone mapping; astro = long stacked exposures. (ACM TOG 2016, Google Research; pixel features lists) → YUVCam analog exists via YUV burst.

MotionCam Pro: RAW video, RAW histograms, per-RGB-channel clipping maps, false color, ISO invariance focus → YUVCam can do per-channel clip maps on YUV, RAW-style histograms.

OpenCamera: auto-aligned HDR w/ ghost removal, focus bracketing, camera2 manual, zebra/focus peaking/histogram, night NR → baselines to beat with YUV-first processing.

Blackmagic/medical scopes: waveform, RGB parade, vectorscope, HDR graticules → portable to YUV viewfinder overlays.

Astro calibration: darks/bias/flats subtraction + stacking = core noise-floor work possible from YUV private-storage captures.

Burst denoising research: alignment + noise-prior integration + temporal averaging; FBA deblur via Fourier accum.

Illuminant estimation: gray world / white patch / shades-of-gray / gray edges / PCA bright-dark → all computable on YUV chroma.

Sensor defect research: hot/stuck pixel maps buildable from many frames; static behavior → one-time calibration fits.

Gyro+RS correction: Karpenko et al. — gyro-calibrated rolling-shutter rectification for stills (usable on single frames at capture).

Mertens exposure fusion: Laplacian pyramid, no tonemap needed → ideal for YUV burst HDR.

Focus stacking: distance-sweep + per-frame sharpness map → depth + all-in-focus; Helicon-style. OpenCamera does brackets; full stack render is differentiator.
